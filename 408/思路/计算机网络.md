# 1 网络层
## 1.1 ICMP

| 报文类型      | 产生原因/场景                                             | 备注                        |
| :-------- | :-------------------------------------------------- | :------------------------ |
| **终点不可达** | 路由器或主机不能交付数据报时。                                     | 分为目的网络、主机、协议、端口不可达等13种错误。 |
| **源点抑制**  | 路由器或主机由于**拥塞**而丢弃数据报时。                              | 通知源点把发送速率放慢。              |
| **时间超过**  | 1. 收到TTL=0的数据报（防止路由环路）。<br>2. 终点在预先规定时间内不能收到所有数据报片。 | 丢弃数据报并向源点报错。              |
| **参数问题**  | IP数据报首部出现**误码**（仅检查部分参数，而非所有参数）。                    | 丢弃数据报并报错。                 |
| **改变路由**  | 路由器发现有更好的路由路径（重定向）。                                 | 让主机知道下次应发给另外的路由器。         |

# 2 其他
## 2.1 协议
### 2.1.1 层次

| 协议   | 所在层 |
| ---- | --- |
| DHCP | 应用层 |
| RIP  | 应用层 |
| BGP  | 应用层 |
| UDP  | 运输层 |
| TCP  | 运输层 |
| ICMP | 网络层 |
| IP   | 网络层 |
| OSPF | 网络层 |

### 2.1.2 端口号

| 协议/描述         | 端口号 |
| ------------- | --- |
| DHCP 服务器端口    | 67  |
| DHCP 客户端端口    | 68  |
| RIP 端口号       | 520 |
| FTP 的控制连接端口号  | 21  |
| FTP 的数据连接端口号  | 20  |
| SMTP 的数据连接端口号 | 25  |
| POP3 的数据连接端口号 | 110 |
| IMAP 的数据连接端口号 | 143 |
| HTTP 的数据连接端口号 | 80  |

### 2.1.3 传输方式

| 协议   | 封装的协议         |
| ---- | ------------- |
| DHCP | UDP           |
| RIP  | UDP           |
| BGP  | TCP           |
| FTP  | TCP           |
| SMTP | TCP           |
| POP3 | TCP           |
| IMAP | TCP           |
| HTTP | TCP           |
| UDP  | IP            |
| TCP  | IP            |
| ICMP | IP            |
| OSPF | IP            |
| IP   | 数据链路层协议（如以太网） |

### 2.1.4 开销

| 协议/数据单元           | 最小首部开销 | 最大首部开销 |
| :---------------- | :----- | :----- |
| **以太网数据帧**        | 18 字节  | 18 字节  |
| **IP 数据报 (IPv4)** | 20 字节  | 60 字节  |
| **TCP 报文段**       | 20 字节  | 60 字节  |
| **UDP 用户数据报**     | 8 字节   | 8 字节   |

### 2.1.5 设备

| 设备    | 工作层次  | 说明                 |
| ----- | ----- | ------------------ |
| 中继器   | 物理层   | 放大、整形信号            |
| 集线器   | 物理层   | 多端口中继器，广播转发        |
| 网桥    | 数据链路层 | 根据 MAC 地址转发帧       |
| 交换机   | 数据链路层 | 多端口网桥，根据 MAC 地址转发帧 |
| 三层交换机 | 网络层   | 具备路由功能，可根据 IP 地址转发 |
| 路由器   | 网络层   | 根据 IP 地址转发分组       |
