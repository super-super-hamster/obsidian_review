# 1 进程
## 1.1 进程互斥需遵循的原则
1.  **空闲让进**：临界区空闲时，应允许一个请求进入临界区的进程立即进入。
2.  **忙则等待**：当已有进程进入临界区时，其他试图进入的进程必须等待。
3.  **有限等待**：对请求访问的进程，应保证能在**有限时间**内进入临界区，即不能被无限插队（防止**进程饥饿**）。
4.  **让权等待**：当进程不能进入临界区时，应立即释放处理机（防止**忙等待**）。

## 2.3 页面置换算法
### 2.3.1 FIFO
存在 **Belady异常**

### 2.3.2 CLOCK
1. 为每个页面设置一个**访问位**（1表示最近访问过，0表示未访问）。
2.  扫描循环队列，若当前页面的访问位为 **1**，则将其置为 **0**，指针指向下一页。
3.  若当前页面的访问位为 **0**，则选择淘汰该页面。

### 2.3.3 改进型 CLOCK
1. 标记位为 $(访问位,修改位)$
2. 第一轮扫描，寻找$(0,0)$
3. 第二轮扫描，寻找$(0,1)$，并将所有扫描过的访问位置0
4. 第三轮扫描，重复第一轮操作
5. 第四轮扫描，重复第二轮操作

# 3 文件
## 3.1 文件分配方式
1. **连续分配**
2. **链接分配**
	1. **隐式链接分配**：FCB中记录文件的**起始块号**和**结束块号**，每个磁盘块中保存指向下一个盘块的指针。
	2. **显示链接分配**：将用于链接的指针显式地存放在一张表中，即**文件分配表(FAT)**。
3. **索引分配**：
	1. 为**每个文件**建立一张**索引表**，记录各逻辑块对应的物理块(类似页表)。
	2. 支持**随机访问**。

---
## 3.2 文件共享
### 3.2.1 硬链接
- 所有文件的默认引用计数值为1，即指向文件本身。
- 所有硬链接同一个文件共享引用计数值。

### 3.2.2 软链接
- 默认引用计数值为1。
- 软链接文件本身相当于一个文件，拥有自己的inode。

- **保存位置**：文件的**FCB**或**索引结点**中增加一张**访问控制表**（ACL）。

# 4 I / O
## 4.1 磁盘
### 4.1.1 每次读/写时间
- 每次读/写时间 = 寻道时间 + 平均旋转延迟 + 读取时间
	- 寻道时间 = 启动磁头臂 + 磁头移动时间
	- 平均旋转延迟 = 旋转半圈的时间
	- 读取时间 = 旋转一个扇区的时间

## 4.2 设备
### 4.2.1 设备分配管理

**1. 核心数据结构**
* **设备控制表 (DCT)**：每个**设备**一张。记录设备类型、标识符、状态、**指向控制器表 (COCT) 的指针**、重复执行次数、**等待队列队首指针**。
* **控制器控制表 (COCT)**：每个**控制器**一张。记录控制器的状态及管辖的设备信息。
* **通道控制表 (CHCT)**：每个**通道**一张。管理通道及其下属控制器。
* **系统设备表 (SDT)**：记录系统中**全部设备**的情况。每个表目包含：设备类型、物理设备名（标识符）、**DCT 指针**、驱动程序入口。

**2. 设备分配的步骤**
1.  根据进程请求的**物理设备名**查找 **SDT**，找到对应的 **DCT**。
2.  **分配设备**：查看 DCT，若设备忙碌则挂入设备等待队列；若空闲则分配，并更新 DCT。
3.  **分配控制器**：根据 DCT 找到 **COCT**，若控制器忙碌则挂入控制器等待队列；若空闲则分配。
4.  **分配通道**：根据 COCT 找到 **CHCT**，若通道忙碌则挂入通道等待队列；若空闲则分配。
    * *注：只有设备、控制器、通道**三者都分配成功**，I/O 分配才算成功，开始数据传送。*

### 4.2.2 设备独立性软件
* **主要功能**：
    1.  **提供统一接口**：向上层提供统一的系统调用（如 `read`/`write`）。
    2.  **设备保护**：类似于文件保护，检查用户对设备的访问权限。
    3.  **差错处理**：对设备产生的错误进行处理。
    4.  **设备分配与回收**：管理临界资源，避免冲突。
    5.  **数据缓冲区管理**：屏蔽设备间数据交换单位大小及传输速度的差异。
    6.  **逻辑设备映射**：建立**逻辑设备名**到**物理设备名**的映射，并选择对应的驱动程序。

### 4.2.3 设备驱动程序
**主要功能**：
* **硬件相关**
    * 将上层的通用命令（如 `read`/`write`）转化为设备能识别的**一系列硬件操作指令**。
    * 设置**设备寄存器**，检查设备状态。

## 4.3 缓冲区
* **定义**：
    * $T$：数据从设备输入到缓冲区的时间。
    * $M$：数据从缓冲区传送到工作区的时间。
    * $C$：CPU处理一块数据的时间。

### 4.3.1 单缓冲
* **处理一块数据的平均耗时**：$$\text{平均耗时} = \max(T, C) + M$$

### 4.3.2 双缓冲
* **处理一块数据的平均耗时**：$$\text{平均耗时} = \max(T, C + M)$$

### 5.7.3 循环缓冲
* **机制**：将多个大小相等的缓冲区链接成一个**循环队列**。
    * **in指针**：指向下一个可以冲入数据的**空缓冲区**。
    * **out指针**：指向下一个可以取出数据的**满缓冲区**。

### 5.7.4 缓冲池
* **维护三种队列**：
    1.  **空缓冲队列**：装有空闲缓冲区。
    2.  **输入队列**：装满输入数据的缓冲区。
    3.  **输出队列**：装满输出数据的缓冲区。
