# 1 进程
## 1.1 进程互斥需遵循的原则
1.  **空闲让进**：临界区空闲时，应允许一个请求进入临界区的进程立即进入。
2.  **忙则等待**：当已有进程进入临界区时，其他试图进入的进程必须等待。
3.  **有限等待**：对请求访问的进程，应保证能在**有限时间**内进入临界区，即不能被无限插队（防止**进程饥饿**）。
4.  **让权等待**：当进程不能进入临界区时，应立即释放处理机（防止**忙等待**）。

## 1.2 死锁
### 1.2.1 四个必要条件
* **互斥条件**：资源必须**互斥使用**。
* **不剥夺条件**：**不能由其他进程强行夺走**，只能主动释放。
* **请求和保持条件**：进程**保持了至少一个资源**，提出新的资源请求，而该资源被其他进程占有。
* **循环等待条件**：存在一种进程资源的**循环等待链**。

### 1.2.2 死锁预防
破坏产生死锁的四个必要条件中的至少一个，以确保系统永远不会进入死锁状态。

### 1.2.3 死锁避免
在资源分配过程中，系统通过算法预测此次分配是否会导致系统进入**不安全状态**，从而决定是否允许分配。 

## 1.3 进程通信
1. **共享存储**：操作系统在内存中划出一块互斥访问的共享存储区。
2. **消息传递**：通过格式化的消息进行传递信息。
3. **管道通信**：
	1. 半双工通信
	2. 仅允许**一个写进程**或**一个读进程**对其操作。
4. **信号**：
	1. 进程从内核态转为用户态时处理信号。
	2. 暂停进程信号和终止进程信号不能阻塞，也不能由用户自定义函数处理。

## 2.2 分页存储管理
### 2.2.1 访存操作
1. **查 TLB**
	1. 若命中，则直接获得物理地址，访问内存
	2. 若未命中，则需要查找内存中的页表
2. **查页表**
	1. 若命中，则获得物理地址，访问内存
	2. 若未命中，处理缺页异常

## 2.3 页面置换算法
### 2.3.1 FIFO
存在 **Belady异常**

### 2.3.2 CLOCK
1. 为每个页面设置一个**访问位**（1表示最近访问过，0表示未访问）。
2.  扫描循环队列，若当前页面的访问位为 **1**，则将其置为 **0**，指针指向下一页。
3.  若当前页面的访问位为 **0**，则选择淘汰该页面。

### 2.3.3 改进型 CLOCK
1. 标记位为 $(访问位,修改位)$
2. 第一轮扫描，寻找$(0,0)$
3. 第二轮扫描，寻找$(0,1)$，并将所有扫描过的访问位置0
4. 第三轮扫描，重复第一轮操作
5. 第四轮扫描，重复第二轮操作

# 3 文件
## 3.1 文件分配方式
1. **连续分配**
2. **链接分配**
	1. **隐式链接分配**：FCB中记录文件的**起始块号**和**结束块号**，每个磁盘块中保存指向下一个盘块的指针。
	2. **显示链接分配**：将用于链接的指针显式地存放在一张表中，即**文件分配表(FAT)**。
3. **索引分配**：
	1. 为**每个文件**建立一张**索引表**，记录各逻辑块对应的物理块(类似页表)。
	2. 支持**随机访问**。

---
## 3.2 文件共享
### 3.2.1 硬链接
- 所有文件的默认引用计数值为1，即指向文件本身。
- 所有硬链接同一个文件共享引用计数值。

### 3.2.2 软链接
- 默认引用计数值为1。
- 软链接文件本身相当于一个文件，拥有自己的inode。

---
## 3.3 文件保护
### 3.3.1 访问控制
- **保存位置**：文件的**FCB**或**索引结点**中增加一张**访问控制表**（ACL）。

# 4 I / O
## 4.1 磁盘
### 4.1.1 每次读/写时间
- 每次读/写时间 = 寻道时间 + 平均旋转延迟 + 读取时间
	- 寻道时间 = 启动磁头臂 + 磁头移动时间
	- 平均旋转延迟 = 旋转半圈的时间
	- 读取时间 = 旋转一个扇区的时间

## 4.2 设备
### 4.2.1 设备独立性软件
* **主要功能**：
    1.  **提供统一接口**：向上层提供统一的系统调用（如 `read`/`write`）。
    2.  **设备保护**：类似于文件保护，检查用户对设备的访问权限。
    3.  **差错处理**：对设备产生的错误进行处理。
    4.  **设备分配与回收**：管理临界资源，避免冲突。
    5.  **数据缓冲区管理**：屏蔽设备间数据交换单位大小及传输速度的差异。
    6.  **逻辑设备映射**：建立**逻辑设备名**到**物理设备名**的映射，并选择对应的驱动程序。

### 4.2.2 设备驱动程序
**主要功能**：
* **硬件相关**
    * 将上层的通用命令（如 `read`/`write`）转化为设备能识别的**一系列硬件操作指令**。
    * 设置**设备寄存器**，检查设备状态。

---
## 4.3 缓冲区
* **定义**：
    * $T$：数据从设备输入到缓冲区的时间。
    * $M$：数据从缓冲区传送到工作区的时间。
    * $C$：CPU处理一块数据的时间。

### 4.3.1 单缓冲
* **处理一块数据的平均耗时**：$$\text{平均耗时} = \max(T, C) + M$$

### 4.3.2 双缓冲
* **处理一块数据的平均耗时**：$$\text{平均耗时} = \max(T, C + M)$$

### 4.3.3 循环缓冲
* **机制**：将多个大小相等的缓冲区链接成一个**循环队列**。
    * **in指针**：指向下一个可以冲入数据的**空缓冲区**。
    * **out指针**：指向下一个可以取出数据的**满缓冲区**。

### 4.3.4 缓冲池
* **维护三种队列**：
    1.  **空缓冲队列**：装有空闲缓冲区。
    2.  **输入队列**：装满输入数据的缓冲区。
    3.  **输出队列**：装满输出数据的缓冲区。
