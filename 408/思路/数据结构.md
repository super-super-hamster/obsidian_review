# 1 线性表
## 1.1 栈
- 当n个不同元素按固定次序入栈时，可能的出栈序列总数为$\frac{1}{n+1}C_{2n}{n}$，即卡特兰数。
### 1.1.1 中缀表达式转后缀表达式
从左到右依次遍历中缀表达式的每一项
1. 遇到操作数时，直接加入后缀表达式
2. 遇到界限符，若为'('，则直接入栈；若为')'，不入栈并不断弹出栈顶运算符加入后缀表达式，直到遇到'('
3. 遇到运算符，若其优先级高于栈顶运算符或栈顶为'('，则直接入栈；若其优先级低于等于栈顶运算符，则不断弹出栈顶运算符加入后缀表达式，直到栈空，或栈顶为'('，或栈顶运算符低于当前运算符为止，再将当前运算符入栈

# 2 树
## 2.1 度
- 结点的度为结点的子结点的个数
- 树的度为结点的度的最大值

## 2.2 路径长度
- 路径上**边的数量**
- **树的路径长度**是从**根结点**到**每个结点**的路径长度的**总和**

# 3 查找
## 3.1 二分查找
- **最多比较次数**：$\lfloor \log_2 n \rfloor + 1$

---
## 3.2 查找二叉树
### 3.2.1 删除
1. 若为叶结点，直接删除
2. 若仅有一个子结点，用子结点代替
3. 若有两个子结点，用中序遍历的直接前驱或直接后继代替

## 3.3 平衡二叉树
- **平衡因子**：左子树高度 - 右子树高度

### 3.3.1 插入
设第一个不平衡结点为 A
- **LL**：对A进行一次左旋
- **RR**：对A进行一次右旋
- **LR**：先对A的左子树进行一次左旋，再对A进行一次右旋
- **RR**：先对A的右子树进行一次右旋，再对A进行一次左旋

### 3.3.2 删除
1. 按平衡二叉树的方法删除
2. 按插入的方式进行旋转

# 4 排序

## 4.1 排序算法
### 4.1.1 直接插入排序
- **思想**：将当前位置的元素插入到前面已经排好序的子序列中

### 4.1.2 希尔排序
- **思想**：给定一个增量d，将所有的$a_i,a_{i+d},a_{i+2d},...$组成的子序列进行直接插入排序，并逐渐缩小增量d

### 4.1.3 冒泡排序
- **思想**：从一个方向开始，将未确定位置的元素不断往前与逆序的元素交换位置。当一趟排序过程中没有交换元素操作时，排序完成。
- **稳定**

### 4.1.4 快速排序
- **思想**：任取一个元素作为枢轴，将关键字更小的放在它的左边，关键字更大的放在右边，并不断递归处理左右子序列。

### 4.1.5 简单选择排序
- **思想**：将当前元素与后面的关键字更小的交换。每次swap共移动元素3次。

### 4.1.6 堆排序
#### 4.1.6.1 堆的定义
1. 完全二叉树
2. 小(大)根堆: 所有节点的值都小于等于(大于等于)子节点的的值。
- **思想**：将初始序列构建成堆，并不断弹出堆顶元素。

### 4.1.7 归并排序
- **思想**：将两个或以上的有序序列合并成一个有序序列

### 4.1.8 基数排序
- **思想**：不断对关键字各位进行排序

---
## 4.2 时空复杂度

| 算法     | 空间复杂度                      | 最好时间复杂度      | 平均时间复杂度        | 最坏时间复杂度      |
| ------ | -------------------------- | ------------ | -------------- | ------------ |
| 直接插入排序 | $O(1)$                     | $O(n)$       | $O(n^2)$       | $O(n^2)$     |
| 希尔排序   | $O(1)$                     | 与增量序列有关      | 约 $O(n^{1.3})$ | $O(n^2)$     |
| 冒泡排序   | $O(1)$                     | $O(n)$       | $O(n^2)$       | $O(n^2)$     |
| 快速排序   | 最好 $O(\log n)$，最坏 $O(n)$   | $O(n\log n)$ | $O(n\log n)$   | $O(n^2)$     |
| 简单选择排序 | $O(1)$                     | $O(n^2)$     | $O(n^2)$       | $O(n^2)$     |
| 堆排序    | $O(1)$                     | $O(n\log n)$ | $O(n\log n)$   | $O(n\log n)$ |
| 归并排序   | $O(n)$                     | $O(n\log n)$ | $O(n\log n)$   | $O(n\log n)$ |
| 基数排序   | 链式 $O(k)$，顺序 $O(n+k)$；默认链式 | $O(d(n+k))$  | $O(d(n+k))$    | $O(d(n+k))$  |

## 4.3 稳定性
### 4.3.1 稳定
- 直接插入排序
- 冒泡排序
- 归并排序
- 基数排序

### 4.3.2 不稳定
- 希尔排序
- 快速排序
- 简单选择排序
- 堆排序
