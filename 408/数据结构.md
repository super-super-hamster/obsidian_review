## 1.1 栈
- 一种操作受限的线性表
- 当n个不同元素按固定次序入栈时，可能的出栈序列总数为$\frac{1}{n+1}C_{2n}{n}$，即卡特兰数。

## 1.2 中缀表达式转后缀表达式
从左到右依次遍历中缀表达式的每一项
1. 遇到操作数时，直接加入后缀表达式
2. 遇到界限符，若为'('，则直接入栈；若为')'，不入栈并不断弹出栈顶运算符加入后缀表达式，直到遇到'('
3. 遇到运算符，若其优先级高于栈顶运算符或栈顶为'('，则直接入栈；若其优先级低于等于栈顶运算符，则不断弹出栈顶运算符加入后缀表达式，直到栈空，或栈顶为'('，或栈顶运算符低于当前运算符为止，再将当前运算符入栈

## 1.3 队列
- 一种操作受限的线性表

## 1.4 循环队列的判断空/满的方法
1. **牺牲一个存储单元**：
	- **队满条件**：$(q.back+1)\%max\_size==q.front$
	- **队空条件**：$q.front==q.back$
2. **增设size成员**：
	- **队满条件**：$q.size==0$
	- **队空条件**：$q.size==max\_size$
3. **增设tag标志位**：
	- **队满条件**：出队后置tag为1，若$q.front==q.back$则队满
	- **队空条件**：出队后置tag为0，若$q.front==q.back$则队空

# 2 串
## 2.1 KMP
### 2.1.1 实现
```C++
// 模式串下标从1开始  
void get_next(const string& t, vector<int>& next) {  
    next[1] = 0;  
    for (int i = 1, j = 0; i < t.length();) {  
        if (j == 0 || t[i] == t[j]) {  
            ++i;  
            ++j;  
            next[i] = j;  
        } else {  
            j = next[j];  
        }  
    }  
}
```

**手算next方法**：
1. $next[1]=0,next[2]=1$
2. 找到最大的n，满足长度为前i个字符中，长度为n的前缀等于长度为n的后缀，且$n \ne i$，则$next[i]=n+1$
### 2.1.2 改进KMP
```C++
void get_nextval(const string& t, vector<int>& nextval) {  
    nextval[1] = 0;  
    for (int i = 1, j = 0; i < t.length();) {  
        if (j ==0 || t[i] == t[j]) {  
            ++i;  
            ++j;  
            if (t[i] == t[j]) nextval[i] = nextval[j];  
            else nextval[i] = j;  
        } else {  
            j = nextval[j];  
        }  
    }  
}
```

**手算nextval方法**：
1. $nextval[1]=0$
2. 如果$t[1]==t[2]$，$nextval[2]=0$，否则$nextval[2]=1$
3. 如果$t[i]==t[next[i]]$，$nextval[i]=nextval[next[i]]$，否则$nextval[2]=next[i]$

# 3 树
## 3.1 树的遍历
### 3.1.1 还原二叉树
- 已知中序遍历序列和其他三种遍历序列中的任何一种即可唯一确定对应二叉树。
- 已知先序遍历序列和后序遍历序列，仅当二叉树为满二叉树时可唯一确定，否则一定不可唯一确定。

### 3.1.2 先根遍历
- 先访问根结点。
- 再依次遍历根结点的每棵子树,遍历子树时仍遵循先根后子树的规则
- 遍历序列与对应二叉树的先序遍历相同

### 3.1.3 后根遍历
- 先依次遍历根结点的每棵子树,遍历子树时仍遵循先子树后根的规则
- 再访问根结点
- 遍历序列与对应二叉树的中序遍历相同，与原树的后序遍历序列相同

---
## 3.2 线索二叉树
- 若某结点无左子树,则将lchild指向其在指定遍历序列中的前驱结点。
- 若某结点无右子树,则将rchild指向其在指定遍历序列中的后继结点。
- 标志域ltag和rtag的含义:
	- ltag=0表示lchild指向左孩子,ltag=1表示lchild指向前驱
	- rtag=0表示rchild指向右孩子,rtag=1表示rchild指向后继

---
## 3.3 哈夫曼树
- **结点的带权路径长度**：根节点到该结点的路径长度与该结点权值的乘积
- **树的带权路径长度/WPL**：所有叶结点的带权路径长度之和
- **加权平均路径长度**：WPL/所有叶结点的权值之和

### 3.4.2 改进并查集
**查找**：
```C++
int find(vector<int>& parent, int x) {
	int root = x;
	while (parent[root] >= 0) root = parent[root];
	
	while (x != root) {
		int tmp = parent[x];
		parent[x] = root;
		x = tmp;
	}
	
	return root;
}
```

**合并**：
```C++
// 若root为根结点，则parent[root]的绝对值的含义为root对应并查集的大小

void merge(vector<int>& parent, int root1, int root2) {
	if (root1 == root2) return;
	if (parent[root2] > parent[root1]) {
		parent[root1] += parent[root2];
		parent[root2] = root1;
	} else {
		parent[root2] += parent[root1];
		parent[root1] = root2;
	}
}
```

## 3.5 二叉树转换
### 3.5.1 树转换为二叉树
- 每个结点的左指针指向其第一个孩子
- 每个结点的右指针指向其在原树中的下一个右兄弟

### 3.5.2 森林转换为二叉树
- 首先将森林中的每棵树分别转换为对应的二叉树
- 可将转换后的二叉树的根结点视为兄弟，再次进行二叉树转换

### 3.5.3 二叉树转换为森林
- 二叉树的根及其左子树对应第一棵树的二叉树表示
- 将根的右指针断开,其右子树即代表剩余森林转换后的二叉树
- 对右子树递归应用相同规则,不断分离出下一棵树,直至右子树为空
- 最后将每棵分离出的二叉树还原为普通树

# 4 图
## 4.1 概念
- **简单路径**：路径序列中不出现重复的顶点
- **连通分量**：无向图中的极大连通子图
- **强连通分量**：有向图中的极大强连通子图

---
## 4.2 图的存储
### 4.2.1 邻接矩阵
- $a[i][j]$表示$(v_i,v_j)/<v_i,v_j>$的边权/是否存在

### 4.2.2 邻接表
包含两种结点：
- **顶点表结点**：$[data, firstarc]$
	- **data**：存储顶点的信息
	- **firstarc**：指针，指向第一条边的边表结点
- **边表结点**：$[adjvex,nextarc]$
	- **adjvex**：邻接的顶点编号
	- **nextarc**：指针，指向下一条边的边表结点

### 4.2.3 十字链表
- 便于找到以某个结点为尾或头的弧，因此容易求得出度和入度
包含两种结点：
- **弧结点**：$[tailvex, headvex, hlink, tlink, (info)]$
	- **tailvex**：弧尾顶点的编号
	- **headvex**：弧头顶点的编号
	- **hlink**：指针，指向下一个弧头相同的弧
	- **tlink**：指针，指向下一个弧尾相同的弧
	- **info**：存储弧的信息
- **顶点结点**：$[data,firstin,firstout]$
	- **data**：顶点的数据信息
	- **firstin**：以该顶点为弧头的第一条弧
	- **firstout**：以该顶点为弧尾的第一条弧

### 4.2.4 邻接多重表
- 用于存储无向图
包含两种结点：
- **边结点**：$[ivex, ilink, jvex, jlink, (info)]$
	- **ivex和jvex**：边连接的两个顶点的编号
	- **ilink**：指针，指向ivex的下一条边
	- **jlink**：指针，指向jvex的下一条边
	- **info**：存储边的信息
- **顶点结点**：$[data,firstedge]$
	- **data**：顶点的数据信息
	- **firstedge**：顶点的第一条弧

## 4.3 最小生成树
### 4.3.1 Prim
```C++
// 每次选择全局边权最小且连接未被加入和已被加入的最小生成树的边
int Prim() {  
    int res = 0;  
    vector<bool> vis(graph.size(), false);  
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;  
  
    vis[0] = true;  
    for (auto [nb, val] : graph[0]) {  
        pq.emplace(val, nb);  
    }  
  
    int cnt = 1;
    while (!pq.empty() && cnt < graph.size()) {  
        auto [w, u] = pq.top();  
        pq.pop();  
  
        if (vis[u]) continue;
  
        vis[u] = true;  
        res += w;  
        cnt++;  
  
        for (auto [v, weight] : graph[u]) {  
            if (!vis[v]) {  
                pq.emplace(weight, v);  
            }  
        }  
    }  
    return res;  
}
```

## 4.4 最短路
### 4.4.1 Dijkstra
- Dijkstra不适用于存在负权边的图
```C++
// vis[i]为true表示i已经找到最短路径
// from[i]为i的最短路径前一个结点
void Dijkstra() {  
    priority_queue<pair<int, int>, vector<pair<int, int>>,greater<>> pq;  
    pq.emplace(0, 0);  
  
    while (!pq.empty()) {  
       auto [d, cur] = pq.top();  
       pq.pop();  
  
       if (vis[cur]) continue;  
  
       vis[cur] = true;  
  
       for (const auto& [w, nb] : graph[cur]) {  
          if (!vis[nb] && dis[cur] + w < dis[nb]) {  
             dis[nb] = dis[cur] + w;  
             from[nb] = cur;
             pq.emplace(dis[nb], nb);  
          }  
       }  
    }  
}
```

## 4.5 AOV 和 AOE
### 4.5.1 AOV
- 顶点表示活动
- 边表示顶点对应的活动之间的先后关系

### 4.5.2 AOE
- 顶点表示事件
- 边表示活动
- 边权表示完成对应活动花费的时间
- **关键路径**：从源点到汇点的路径中，路径长度最大的路径
- **关键活动**：关键路径上的活动
- **事件最早发生时间$v_e(i)$**：
	- $v_e(源点)$=0
	- $v_e(i)=Max\{v_e(j)+w(i,j)\}$
	- i为j的任意后继
- **事件最迟发生时间v_l(i)**:
	- $v_l(汇点)=v_e(汇点)$
	- $v_l(i)=Min\{v_l(j)-w(i,j)\}$
	- i为j的后继
- **活动最早开始时间e(i)**：$e(i)=v_e(k)$
- **活动最迟开始时间l(i)**：
	- $l(i)=v_l(j)-w(i,j)$
	- i为j的前驱

# 5 查找
## 5.1 二分查找
```C++
int binary(const vector<int>& a, const int t) {  
    int l = 0, r = a.size() - 1;  
    while (l <= r) {  
        const int mid = (l + r) / 2;  
        if (a[mid] == t) return mid;  
        if (a[mid] > t) r = mid - 1;  
        else l = mid + 1;  
    }  
      
    return -1;  
}
```

- **平均查找长度**：$ASL=\frac{n+1}{n} \log_2(n+1)$

## 5.3 红黑树
- 根和叶子(NULL)都是黑色
- 不存在连续的两个红色结点
- 任一结点到叶所有路径黑结点数量相同
- **插入**：
	- 默认插入结点为红色
	- 若插入结点为根结点，直接变为黑色
	- 若插入结点的父结点为红色
		- 若插入结点的叔结点为红色，父、爷和叔三个结点变色，并将爷结点视作插入结点，继续检查
		- 若插入结点的叔结点为黑色，父和爷结点变色
			- **LL**：爷结点右旋
			- **RR**：爷结点左旋
			- **LR**：先对父节点左旋，再对爷结点右旋
			- **RL**：先对父节点右旋，再对爷结点左旋
- **结论**：
	- 从根到叶结点的最长路径不大于最短路径的两倍
	- 有n个内部结点的红黑树的高度小于等于$2\log_2(n+1)$

## 5.4 B 树
对于m阶的B 树：
- 每个结点至多有m棵子树，即最多m+1个关键字
- 若根节点不是叶结点，则至少有2棵子树
- 除根结点外，所有非叶结点至少有$\lceil m/2 \rceil$棵子树

---
## 5.5 B+ 树
与B 树的不同之处：
- n个关键字对应n个子树
- 关键字都存储在叶结点，其他结点仅用于索引，而B 树的关键字存储在所有结点上
- 支持顺序查找

## 5.6 散列表
### 5.6.1 散列函数
1. **直接定址法**：$H(key)=a \cdot key + b$，其中$a \ne 0$。直接定址法不会产生冲突。
2. **除留余数法**：$H(key) = key \% p$
3. **数字分析法**：选择较为均匀的数位作为散列地址
4. **平方取中法**：取关键字平方值的中间几位作为散列地址

### 5.6.2 处理冲突
1. **开放地址法**：$H_i=(H(key)+d_i)\%m$，其中 $d_i$为第i次探测的增量
	- **线性探测法**：$d_i=i$。容易引发“聚集”现象
	- **平方探测法**：$d_i=1^2,-1^2,2^2,-2^2...$。其中m必须为形如$4k+3$的质数。无法探测所有位置，但至少能探测到一半。
	- **双散列法**：$d_i=i \cdot H_2(key)$
	- **删除**：删除元素后仅作标记，并不真正删除。当查找到删除标记时，应继续查找。
2. **拉链法**：将同义词组织成一个链表

### 5.6.3 查找效率
查找效率主要取决于散列函数、冲突处理和装填因子。
其中装填因子$\alpha=\frac{表中记录数n}{散列表长度m}$

# 6 排序
## 6.1 插入排序
### 6.1.1 直接插入排序
- **思想**：将当前位置的元素插入到前面已经排好序的子序列中
- **稳定**
- **空间复杂度**：$O(1)$
- **时间复杂度**：$O(n^2)$
- **适用性**：适用于链式存储和顺序存储的线性表

### 6.1.2 希尔排序
- **思想**：给定一个增量d，将所有的$a_i,a_{i+d},a_{i+2d},...$组成的子序列进行直接插入排序，并逐渐缩小增量d
- **不稳定**
- **空间复杂度**：$O(1)$
- **时间复杂度**：通常约为$O(n^{1.3})$，最坏情况下$O(n^2)$
- **适用性**：仅适用于顺序存储的线性表

---
## 6.2 交换排序
### 6.2.1 冒泡排序
- **思想**：从一个方向开始，将未确定位置的元素不断往前与逆序的元素交换位置。当一趟排序过程中没有交换元素操作时，排序完成。
- **稳定**
- **空间复杂度**：$O(1)$
- **时间复杂度**：$O(n^2)$
- **适用性**：适用于链式存储和顺序存储的线性表

### 6.2.2 快速排序
- **思想**：任取一个元素作为枢轴，将关键字更小的放在它的左边，关键字更大的放在右边，并不断递归处理左右子序列。
- **不稳定**
- **空间复杂度**：取决于划分方式，最好情况下为$O(logn)$，最坏情况下为$O(n)$
- **时间复杂度**：最好情况下为$O(nlog n)$，最坏情况下为$O(n^2)$
- **适用性**：仅适用于顺序存储的线性表

---
## 6.3 选择排序
### 6.3.1 简单选择排序
- **思想**：将当前元素与后面的关键字更小的交换。每次swap共移动元素3次。
- **不稳定**
- **空间复杂度**：$O(1)$
- **时间复杂度**：$O(n^2)$
- **适用性**：适用于链式存储和顺序存储的线性表

### 6.3.2 堆排序
- **思想**：将初始序列构建成堆，并不断弹出堆顶元素。
- **不稳定**
- **空间复杂度**：$O(1)$
- **时间复杂度**：建堆时间复杂度$O(n)$，每次调整时间复杂度$O(logn)$，总时间复杂度$O(nlogn)$
- **适用性**：仅适用于顺序存储的线性表

---
## 6.4 归并排序
- **思想**：将两个或以上的有序序列合并成一个有序序列
- **稳定**
- **空间复杂度**：$O(n)$
- **时间复杂度**：$O(nlogn)$
- **适用性**：适用于链式存储和顺序存储的线性表

---
## 6.5 基数排序
- **思想**：不断对关键字各位进行排序
- **稳定**
- **空间复杂度**：顺序存储时$O(n+k)$，链式存储时$O(k)$，默认链式存储，其中k为队列个数
- **时间复杂度**：$O(d(n+k))$，其中d为排序趟数
- **适用性**：适用于链式存储和顺序存储的线性表
