# 2 CPU
## 2.1 微指令字段编码方式
1. **直接编码**：每一位直接对应一个微命令。
2. **字段直接编码方式**：互斥性微命令归入同一字段，相容性微命令分配到不同字段。
3. **字段间接编码**：微命令字段的实际含义由另一个字段的编码共同决定。可进一步压缩微指令长度。

## 2.2 多处理器
1. **SISD(单指令流单数据流)**
2. **SIMD(单指令流多数据流)**：所有处理单元同时处理同一条指令，但各自拥有独立的寄存器，可以同时操作不同的数据。例如，处理循环时，可并行计算多组数据。
	1. **向量处理器**：一条指令可对一组数据，即向量，执行相同操作。适用于规则计算场景。
3. **MIMD(多指令流多数据流)**：
	1. 消息传递型，不共享地址空间，依赖消息传递进行通信。
	2. 共享存储型，具有统一的全局地址空间。

### 多核处理器
- 共享高层级 Cache。

## 2.3 其他
- **动态流水线**：流水线可以由硬件动态调度，允许多条指令以不同顺序，不同重叠方式执行。支持乱序执行、动态分支预测。

# 3 其他
- **编译器的作用**：将高级语言源程序一次性翻译为汇编语言或机器语言。
- **汇编器的作用**：将汇编语言源程序翻译为机器语言目标程序。
- **解释器的作用**：逐条翻译并立即执行高级语言源程序语句，不生成独立的目标程序。
- **链接器的作用**：把多个目标文件和库合并成一个可执行文件，并完成地址绑定。
