# 2 CPU
## 2.1 微指令字段编码方式
1. **直接编码**：每一位直接对应一个微命令。
2. **字段直接编码方式**：互斥性微命令归入同一字段，相容性微命令分配到不同字段。
3. **字段间接编码**：微命令字段的实际含义由另一个字段的编码共同决定。可进一步压缩微指令长度。

## 2.2 多处理器
1. **SISD(单指令流单数据流)**
2. **SIMD(单指令流多数据流)**：所有处理单元同时处理同一条指令，但各自拥有独立的寄存器，可以同时操作不同的数据。例如，处理循环时，可并行计算多组数据。
	1. **向量处理器**：一条指令可对一组数据，即向量，执行相同操作。适用于规则计算场景。
3. **MIMD(多指令流多数据流)**：
	1. 消息传递型，不共享地址空间，依赖消息传递进行通信。
	2. 共享存储型，具有统一的全局地址空间。

### 2.2.1 硬件多线程
为每个线程配备独立的寄存器，线程切换时，只需激活对应的寄存器，从而大幅降低切换开销。
1. **细粒度多线程**：每个时钟周期切换线程。
2. **粗粒度多线程**：连续处理同一线程，仅当流水线阻塞时才切换线程。
3. **同时多线程**：线程级并行

### 2.2.2 多核处理器
- 共享高层级 Cache。

### 2.2.3 SMP
**共享内存多处理器/SMP**：共享单一物理地址空间的多处理系统，
1. **统一存储访问/UMA**：所有 CPU 访问任意内存单元的延迟基本相同。
2. **非统一存储访问/NUMA**：内存访问延迟取决于 CPU 与目标内存的物理位置关系。

## 2.3 其他
- **动态流水线**：流水线可以由硬件动态调度，允许多条指令以不同顺序，不同重叠方式执行。支持乱序执行、动态分支预测。

# 3 I/O
## 3.1 I/O 接口
### 3.1.1 功能
- 地址译码
- 缓冲
- 信号格式转换

### 3.1.2 类型
- 并行接口、串行接口
- 程序查询接口、中断接口、DMA 接口
- 可编程接口(CPU 可向控制寄存器写入控制字，修改接口的工作方式等)、不可编程接口

## 3.2 I/O 端口
- 可被 CPU 直接访问的寄存器，包括数据端口、状态端口和控制端口。
- 端口是接口内部的寄存器

# 4 其他
- **编译器的作用**：将高级语言源程序一次性翻译为汇编语言或机器语言。
- **汇编器的作用**：将汇编语言源程序翻译为机器语言目标程序。
- **解释器的作用**：逐条翻译并立即执行高级语言源程序语句，不生成独立的目标程序。
- **链接器的作用**：把多个目标文件和库合并成一个可执行文件，并完成地址绑定。
