# 1 数据的表示和运算
## 1.1 类型转换
- **长类型转短类型**：位截断。可能由于位截断导致转换前后的正负不同。
- **相同字长转换**：二进制位不改变，仅改变解释方式。
- **短类型转长类型**：若源数据为有符号数，则进行符号扩展，否则零扩展。

## 1.2 浮点数
### 1.2.1 舍入
在对阶和右规过程中，尾数右移可能导致低位丢失。为保证精度，将移出的低位保留用于中间计算。
- **保护位**：尾数最低有效位后的第一位。
- **舍入位**：尾数最低有效位后的第二位。
- **粘滞位**：只要舍入位之后被移除的位中至少存在一个1，粘滞位就为1，否则为0。
- **就近舍入**：选择最接近真实值的可表示的那个数，若恰好位于两个可表示数中间，则选择最低有效位为0的。
	1. 若保护位为0，则直接舍去。
	2. 若保护位为1，且舍入位和粘滞位中至少一个为1，则尾数+1。
	3. 若保护位为1，舍入位和粘滞位都为0，则在尾数末位为1时+1。

### 1.2.2 非规格化浮点数
1. **阶码**：固定为$1 - \text{偏置值}$。
2. **尾数**：小数点前补 0。

## 1.3 无符号整数乘法电路
计算 $X \times Y$
1. 乘积寄存器置 0。
2. 将 $[P,Y]$ 视作一个整体 $Z$。
3. 若 $Z$ 的最低位为 1，则将 $X$ 加到 $Z$ 的高 n 位。
4. 将 $Z$ 逻辑右移一位，返回步骤3，直到执行 n 次。
5. 若 $P$ 不为 0，则说明发生溢出。

## 1.4 无符号整数除法电路
计算 $X \div Y$
1. 若 $X$ 不足 $2n$ 位，则高位补 0 至 $2n$ 位。
2. 余数寄存器置 0。
3. 将 $[R,X]$  视作一个整体 $Z$。
4. 将 $Z$ 逻辑左移一位。
5. 计算 $R-Y=C$
	1. 若 $C \ge 0$，则 $X+1,R=C$
	2. 若 $C < 0$，则执行 $R=R+Y$，恢复余数
6. 返回步骤 4，直到执行 n 次。
7. 商保存在 $X$ 中，余数保存在 $R$ 中。

# 2 存储系统
## 2.1 Cache
### 2.1.1 写策略
1. **写命中**
	1. **全写法**：同时向 Cache 和主存写入数据。
	2. **回写法**：仅修改 Cache 中的副本。只有当该 Cache 行被替换时，才将其写回主存。
2. **写不命中**
	1. **非写分配法**：直接向主存写入数据，不将该块调入 Cache。
	2. **写分配法**：先将主存中的目标块调入 Cache，然后在 Cache 中进行修改。
3. 通常全写法与非写分配法搭配，回写法与写分配法搭配。

- 通过 `NMI` 信号线发出的是不可屏蔽中断

# 4 总线
## 4.1 数据传输方式
- **非突发传输**：每次仅传输一个数据单元。每次传输都必须经历完整的“发地址 $\rightarrow$ 等待 $\rightarrow$ 传数据”流程。
- **突发传输**：连续传输多个数据单元。主设备仅在事务开始时发送**首地址**，后续地址由硬件自动递增生成。
