# 1 进程
## 1.1 进程通信
1. **共享存储**：操作系统在内存中划出一块互斥访问的共享存储区。
2. **消息传递**：通过格式化的消息进行传递信息。
3. **管道通信**：
	1. 半双工通信
	2. 一个管道允许**多个写进程**，但只允许**一个读进程**，防止数据错乱。
4. **信号**：
	1. 进程从内核态转为用户态时处理信号。
	2. 暂停进程信号和终止进程信号不能阻塞，也不能由用户自定义函数处理。

## 1.2 调度算法
### 1.2.1 多级反馈队列
* **设置多级队列**：优先级逐级降低，时间片逐级增大。
* **新进程流程**：
    * 新进程进入**第 1 级**队列队尾。
    * 按 **FCFS** 原则排队等待被分配时间片。
    * 若在时间片内未执行完，则**降级**进入**下一级**队列队尾。
* **调度时机**：只有第 $k$ 级队列为空时，才会为第 $k+1$ 级队头的进程分配时间片。

## 1.3 管程
- **条件变量**：支持`wait`和`signal`。
	- 其中，`wait` 和 `signal` 操作与PV操作并不相同，`wait` 仅负责将线程加入等待队列，`signal` 仅负责唤醒等待队列中的一个线程。

# 2 内存
## 2.1 内存映射文件
- 在磁盘文件与进程的虚拟地址空间之间建立直接映射关系。将文件映射到进程虚拟地址空间的某一区域，此后便可像访问内存一样读/写文件。
- 通过将同一文件映射到多个通信进程的虚拟地址空间可实现进程间的通信。

## 2.2 其他
- **对换区**：采用**连续分配**，读写速度**快**。
- **文件区**：采用**离散分配**，读写速度**慢**。

# 3 文件
## 3.1 设备
### 3.1.1 设备分配管理

**1. 核心数据结构**
* **设备控制表 (DCT)**：每个**设备**一张。记录设备类型、标识符、状态、**指向控制器表 (COCT) 的指针**、重复执行次数、**等待队列队首指针**。
* **控制器控制表 (COCT)**：每个**控制器**一张。记录控制器的状态及管辖的设备信息。
* **通道控制表 (CHCT)**：每个**通道**一张。管理通道及其下属控制器。
* **系统设备表 (SDT)**：记录系统中**全部设备**的情况。每个表目包含：设备类型、物理设备名（标识符）、**DCT 指针**、驱动程序入口。

**2. 设备分配的步骤**
1.  根据进程请求的**物理设备名**查找 **SDT**，找到对应的 **DCT**。
2.  **分配设备**：查看 DCT，若设备忙碌则挂入设备等待队列；若空闲则分配，并更新 DCT。
3.  **分配控制器**：根据 DCT 找到 **COCT**，若控制器忙碌则挂入控制器等待队列；若空闲则分配。
4.  **分配通道**：根据 COCT 找到 **CHCT**，若通道忙碌则挂入通道等待队列；若空闲则分配。
    * *注：只有设备、控制器、通道**三者都分配成功**，I/O 分配才算成功，开始数据传送。*

## 3.2 存储空间管理
1. **空闲表法**：为每个文件分配一个物理上连续的磁盘区域。系统为所有空闲区维护一张空闲表。
2. **空闲链表法**
3. **位示图法**
4. **成组链接法**
    * **索引块**：每组的第一个块。系统启动时读入内存，记录**下一组空闲盘块数**及**下一组所有空闲盘块号**。
	* **分配操作**：
	    1.  检查超级块中空闲数是否足够。
	    2.  若足够且非该组最后一个块时直接分配。
	    3.  若分配的是该组**最后一个空闲块**，需先将该块中的信息复制到索引块中，再进行分配。

## 3.3 虚拟文件系统
* VFS 向**用户进程**提供统一标准的**系统调用**接口（如 `open`, `read`, `write`）。
* 当使用 `open` 系统调用**打开**一个文件时，VFS 会在**主存**中新建一个 `vnode`。无论底层是何种文件系统，VFS 都会将文件的相关元数据复制到 `vnode` 中，形成统一格式。

# 4 I / O
## 4.1 SPOOLing
* **定义**：用**软件**的方式模拟脱机技术。SPOOLing 系统建立在**多道程序技术**之上。
* **系统组成**：
    1.  **输入井和输出井**：在**磁盘**上开辟的两个存储区域，用于暂存输入/输出设备的数据，并将输入/输出数据以文件形式保存，称为井文件。
    2.  **输入缓冲区和输出缓冲区**：在**内存**中开辟的缓冲区。输入缓冲区暂存由输入设备送来的数据，随后传送到输入井。输出缓冲区暂存从输出井读出的数据，随后传送到输出设备。
    3. **输入进程**：将输入设备的数据经输入缓冲区传送到输入井，当CPU需要输入数据时，直接从输入井读取。
    4. **输出进程**：将输出数据写入输出井，并在输出设备空闲时，井输出缓冲区将数据传送到输出设备。

## 4.2 其他
-  **I/O 端口**：设备控制器中可被CPU访问的寄存器

# 5 其他
## 5.1 操作系统引导
1. **CPU激活与BIOS初始化**：CPU从ROM中读取并执行BIOS程序，BIOS初始化基本硬件，**建立中断向量表**。
2. **硬件自举与启动设备选择**：BIOS执行通电自检，之后选择首个有效的启动设备。
3. **加载主引导记录(MBR)**：BIOS将主引导记录加载到内存中。MBR包含引导代码和硬盘分区表。
4. **加载分区引导记录**：根据分区表找到活动分区后，将该分区的第一个扇区，即 引导记录 (PBR) 读入内存。
5. **加载操作系统初始化程序**：从根目录中找到 启动管理器。
