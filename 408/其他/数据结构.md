# 1 树
## 1.1 线索二叉树
**头结点**：
- `LTag = 0`，`RTag = 1`。
- 头结点的 `lchild` 指向二叉树的**根结点**；头结点的 `rchild` 指针**反向指向遍历序列中的最后一个结点**；
- 当二叉树为空树时，头结点的 `lchild` 与 `rchild` 均指向头结点自身。

# 2 图
## 2.1 十字链表
1. 弧结点：$[$ tailvex, headvex, hlink, tlink, (info) $]$
	- tailvex：弧尾顶点的编号
	- headvex：弧头顶点的编号
	- hlink：指针，指向下一个弧头相同的弧
	- tlink：指针，指向下一个弧尾相同的弧
	- info：存储弧的信息
2. 顶点结点：$[$ data, firstin, firstout $]$
	- data：顶点的数据信息
	- firstin：以该顶点为弧头的第一条弧
	- firstout：以该顶点为弧尾的第一条弧

## 2.2 邻接多重表
1. 边结点：$[$ ivex, ilink, jvex, jlink, (info) $]$
	- ivex 和 jvex：边连接的两个顶点的编号
	- ilink：指针，指向ivex的下一条边
	- jlink：指针，指向jvex的下一条边
	- info：存储边的信息
2. 顶点结点：$[$ data, firstedge $]$
	- data：顶点的数据信息
	- firstedge：顶点的第一条弧

# 4 其他
## 4.1 数据结构的基本概念
* **数据**：信息的载体，客观事物的符号表示，能输入计算机并被程序处理的符号总称。
* **数据元素**：数据的基本单位，通常作为一个整体进行考虑和处理。
* **数据项**：组成数据元素的、有独立含义的、不可分割的最小单位。
* **数据对象**：性质相同的数据元素的集合，是数据的一个子集。
- **数据结构**：包含**逻辑结构**和**存储结构**两个层次。
	- **逻辑结构**：包含两要素，**数据元素**和**关系**。
		1. **集合结构**：元素间“属于同一集合”。
		2. **线性结构**：元素间存在**一对一**的关系。
		3. **树结构**：元素间存在**一对多**的关系。
		4. **图结构/网状结构**：元素间存在**多对多**的关系。
	- **存储结构**：数据的逻辑结构在计算机中的存储表示。
		1. **顺序存储结构**
		2. **链式存储结构**

## 4.2 算法的基本概念
- 一个有效的算法应该具备的五个重要特性：有穷性、确定性、可行性、输入和输出。
- 好的算法应该满足：正确性、可读性、健壮性和高效率和低存储需求。
