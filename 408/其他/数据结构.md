# 1 树
## 1.1 线索二叉树
**头结点**：
- `LTag = 0`，`RTag = 1`。
- 头结点的 `lchild` 指向二叉树的**根结点**；头结点的 `rchild` 指针**反向指向遍历序列中的最后一个结点**；
- 当二叉树为空树时，头结点的 `lchild` 与 `rchild` 均指向头结点自身。

# 2 图
## 2.1 十字链表
1. 弧结点：$[$ tailvex, headvex, hlink, tlink, (info) $]$
	- tailvex：弧尾顶点的编号
	- headvex：弧头顶点的编号
	- hlink：指针，指向下一个弧头相同的弧
	- tlink：指针，指向下一个弧尾相同的弧
	- info：存储弧的信息
2. 顶点结点：$[$ data, firstin, firstout $]$
	- data：顶点的数据信息
	- firstin：以该顶点为弧头的第一条弧
	- firstout：以该顶点为弧尾的第一条弧

## 2.2 邻接多重表
1. 边结点：$[$ ivex, ilink, jvex, jlink, (info) $]$
	- ivex 和 jvex：边连接的两个顶点的编号
	- ilink：指针，指向ivex的下一条边
	- jlink：指针，指向jvex的下一条边
	- info：存储边的信息
2. 顶点结点：$[$ data, firstedge $]$
	- data：顶点的数据信息
	- firstedge：顶点的第一条弧
