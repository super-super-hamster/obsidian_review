# 1 字符串
## 1.1 KMP
**手算 next 方法**：
1. $next[1]=0,next[2]=1$
2. 找到最大的 n，满足长度为前 i 个字符中，长度为 n 的前缀等于长度为 n 的后缀，且 $n \ne i$，则 $next[i]=n+1$

**手算 nextval 方法**：
1. $nextval[1]=0$
2. 如果 $t[1]==t[2]$，$nextval[2]=0$，否则 $nextval[2]=1$
3. 如果 $t[i]==t[next[i]]$，$nextval[i]=nextval[next[i]]$，否则 $nextval[2]=next[i]$

# 3 排序
## 3.1 外部排序
减少归并趟数，可减少磁盘 I/O 次数。
### 3.1.1 败者树
- 结点记录败者的数值和来自段号
- 使用败者树后，内部归并的比较次数与归并路数无关。因此可以通过增大归并路数，从而减少归并趟数。

### 3.1.2 置换选择排序
初始待排文件 $FI$，归并输出文件 $FO$，工作区 $WA$
1. 从 $FI$ 中读取文件，充满 $WA$。
2. 从 $WA$ 中选取最小且大于 $FI$ 中最大元素的元素，写入 $FO$。即保证 $FO$ 单增。
3. 读取一个元素至 $WA$。
4. 重复直至 $WA$ 无法找到元素可写入 $FO$，当前 $FO$ 即为一个归并段。
