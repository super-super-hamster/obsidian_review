# 1 积分
1. 积分号内存在 $f'(x)$，可以尝试化为 $df(x)$。
2. 积分号内存在 $f(x)$，可以尝试使用积分中值定理。
3. 使用高斯公式/格林公式，先检查方向；若需要补面，则需要**先计算散度/旋度**。
4. 使用极坐标系进行计算时，检查**半径的积分范围**。尤其小心误将半径的平方作为上限。
5. 进行和函数相关计算时，要注意 $(-1)^n$ 项。
6. 对于 $\int f(x)e^{g(x)}dx$，可以尝试使用 $\Gamma$ 函数或凑标准正态分布，通过分布函数或 $EX$ 等数字特征解得。
7. 计算定积分时，注意上下限，尤其是换元后。
8. 计算体积积分时，不能把表面方程代入。计算面积积分时，不能将曲线积分代入。

# 2 线性代数
1. 非齐次方程组的解的差为对应齐次方程组的解。
2. 矩阵性质相关问题，优先从**秩和特征值**的角度考虑。

# 3 概率论与数理统计
1. 求得的概率密度和分布函数**要写明区间**。
2. 看清题目求的是**概率密度**还是**分布函数**。

# 4 其他
1. 写答题卡前，先**看清题号**。
2. **做完选择题，把答案填到答题卡上**。
3. 求函数，最后要**写定义域**。
4. 计算前，尤其是复杂函数，先**尝试化简或检查奇偶性**。
5. 一点处的**切线方程** $y-y_0=y'(x-x_0)$。
6. $x^0=1$。
7. 解具体微分方程，需要特殊点的值消去未知变量时，**优先带好计算的数**，如 $y(0),y'(0)$。
8. 使用拉格朗日数乘法，尽量找到**所有解**。
