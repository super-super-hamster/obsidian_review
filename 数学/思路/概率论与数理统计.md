## 1.1 期望和方差

| 分布          | 记号                                                    | 期望                      | 方差                                                              |
| ----------- | ----------------------------------------------------- | ----------------------- | --------------------------------------------------------------- |
| 0-1 分布      | $X \sim B(1,p)$                                       | $EX=p$                  | $DX=p(1-p)$                                                     |
| 二项分布        | $X \sim B(n,p)$                                       | $EX=np$                 | $DX=np(1-p)$                                                    |
| 泊松分布        | $X \sim P(\lambda)$                                   | $EX=\lambda$            | $DX=\lambda$                                                    |
| 几何分布        | $X \sim G(p)$                                         | $EX=\frac{1}{p}$        | $DX=\frac{1-p}{p^2}$                                            |
| 超几何分布       | $X \sim H(n,N,M)$                                     | $EX=n\cdot \frac{M}{N}$ | /                                                               |
| 均匀分布        | $X \sim U(a,b)$                                       | $EX=\frac{a+b}{2}$      | $DX=\frac{(b-a)^2}{12}$                                         |
| 指数分布        | $X \sim E(\lambda)$                                   | $EX=\frac{1}{\lambda}$  | $DX=\frac{1}{\lambda^2}$                                        |
| 一维正态分布      | $X \sim N(\mu,\sigma^2)$                              | $EX=\mu$                | $DX=\sigma^2$                                                   |

| $\chi^2$ 分布 | $X \sim \chi^2(n)$                                    | $EX=n$                  | $DX=2n$                                                         |
| $t$ 分布      | $t \sim t(n)$                                         | $Et=0$                  | $Dt=\frac{n}{n-2}\ (n>2)$                                       |

# 2 统计量
## 2.1 结论
- $E(\bar{X})=E(X)$
- $E(S^2)=D(X)$
- 仅当$X \sim N(\mu, \sigma^2)$ 时成立：
	1. $\bar{X}$ 与 $S^2$ 互相独立
	2. $$\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right)$$
	3. $$\frac{\sqrt{n}(\bar{X}-\mu)}{S} \sim t(n-1)$$
	4. $$\sum \left( \frac{X_i-\mu}{\sigma} \right)^2 \sim \chi^2(n)$$
	5. $$\frac{(n-1)S^2}{\sigma^2}=\sum \left( \frac{X_i-\bar{X}}{\sigma} \right)^2 \sim \chi^2 (n-1)$$
