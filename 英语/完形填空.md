# 1 逻辑关系词题

逻辑关系词本身的实义通常不强，主要作用是标记上下文关系。解题时不要先凭记忆挑连接词，而应先判断关系，再从选项中选择用法正确的表达。

## 1.1 逻辑关系

### 1.1.1 并列
**特征**：前后同方向、同层次
- `and`：和，与，以及
- `or`：或者，或
- `similarly`：类似地，同样地
- `likewise`：同样地
- `as well as`：以及，也

### 1.1.2 递进
**特征**：同方向，后项更强或更重要
- `also`：也，还
- `besides`：此外，而且
- `in addition`：此外，另外
- `moreover`：此外，而且
- `what's more`：而且，更重要的是
- `indeed`：确实，的确。表示强调，引出另一件事。
- `even`：甚至

### 1.1.3 因果
**特征**：一方是原因，另一方是结果
- `because`：因为
- `since`：因为，既然
- `therefore`：因此，所以
- `thus`：因此，于是
- `as a result`：因此，结果
- `now that`：由于，因为
- `put down to`：归因于

### 1.1.4 对立
**特征**：方向、事实、评价或预期相反。出现not，others。
- `but`：但是
- `yet`：然而，但是
- `however`：然而，不过
- `although`：虽然，尽管
- `while`：然而，尽管（表对比）
- `rather than`：而不是
- `instead of`：代替，而不是
- `instead`：句首通常翻译为相反，句中通常翻译为反而，句尾都可
- `though`：不过，可是，然而
- `even if`, `even though`：尽管`
- `even`：即使
- `whereas`：然而
- `yet`：然而，但

### 1.1.5 列举
**特征**：围绕同一观点依次展开分项
- `first`：首先
- `second`：其次，第二
- `next`：接着，下一步
- `finally`：最后

### 1.1.6 条件
**特征**：一方成立是另一方发生的条件
- `if`：如果
- `unless`：除非
- `otherwise`：否则
- `provided`：假如，只要
- `as long as`：只要
- `in case`：万一，如果

### 1.1.7 举例/总分
**特征**：一般概念后接具体实例
- `for example`：例如
- `for instance`：例如
- `such as`：比如，诸如

## 1.2 并列与递进的区别

两者都属于同方向逻辑，区别在语气层级：

- **并列**：前后地位大体相同，只是增加同类信息；
- **递进**：后项比前项更进一步，程度更深、范围更广或重要性更高。

判断时不要只看中文都能否译成“而且”，而要观察后项是否明显加重。

## 1.3 对立关系的识别

当上下文出现明显反差时，应重点寻找对立标志，例如：

- 前面肯定，后面否定；
- 前面评价积极，后面评价消极；
- 实际结果与通常预期相反；
- 两种观点、条件或做法相互冲突。

顺承关系有时可以不使用显式连接词，而明显的对立通常需要语言标志。因此，对立是逻辑关系题中的重要突破口。

## 1.4 列举与举例不能混淆

- **列举**：在同一层级依次展开多个分项，如第一、第二、第三。
- **举例**：先给出上位或一般概念，再给出一个具体成员或实例。

判断举例关系时，可问：后面的具体对象是否属于前面的类别？若属于，通常是“总—分”关系。

## 1.5 因果词不能机械成对出现

原因标志与结果标志通常不会在同一结构中重复出现。判断因果关系时，应先确定空格需要引出原因还是结果，再选择相应表达，避免只因句子涉及原因就随意选因果词。

## 1.6 条件不等于对立

`otherwise` 等词虽然在中文中可能让人感觉语义发生变化，但其核心是“若不满足前述条件，就会出现另一结果”，属于条件逻辑。判断逻辑类别时应还原完整关系，而不是依赖单个中文译义。

## 1.7 意思相近，还要比较用法

多个选项可能都能表示同一种逻辑，但仍需检查：

- 位于句首、句中还是句末；
- 与后面的例子之间是否需要逗号；
- 后接词、短语还是完整从句；
- 是否必须与另一结构搭配；
- 语气强弱是否符合上下文。

**逻辑相同不等于用法相同。** 标点和位置也可以成为决定答案的证据。

# 2 根据空格位置判断

## 2.1 空格位于句中

优先比较空格前后的词、短语或分句。重点检查：

- 两侧语义关系；
- 固定搭配；
- 结构是否平行；
- 空格是否连接一般概念与具体实例；
- 空格前后是否出现正反方向变化。

## 2.2 空格位于句首

句首填逻辑关系词题时，首先考虑对立，其次考虑递进。

句首逻辑词可能表示两种关系：

- 本句内部两个分句之间的关系；
- 本句与前一句之间的关系。

因此必须同时阅读前一句和本句，不能只盯着空格后的内容。

## 2.3 空格处于两个逗号之间

这种位置往往具有插入语特征。可暂时把逻辑词移到句首理解，但必须判断它实际连接的是：

- 本句内部的两部分；还是
- 本句与前一句。

若去掉插入部分后，本句只是完整、自然的主谓宾结构，空格所表达的关系很可能来自句间而非句内。

# 3 选项比较与排除

## 3.1 同义相斥

单选题必须存在唯一最佳答案。如果两个选项在当前语境中的含义和用法完全相同，那么二者通常都不是答案，因为无法形成唯一选择。

但“同义相斥”有严格前提：

- 含义确实相同；
- 语气和感情色彩相同；
- 句法位置和搭配也相同。

若含义相近但标点、位置、搭配或语气不同，就不能机械地同时排除，而应比较具体用法。

## 3.2 利用反义选项确定方向

选项中出现一组反义词时，往往提示命题人在考查上下文的语义方向。此时先根据文章判断需要正向还是负向、增强还是减弱，再在对应方向中精确选择。

反义选项只是方向提示，不能替代最终的搭配和语义验证。

## 3.3 比较感情色彩和语气强弱

近义词可能分别带有正面、负面或中性色彩，也可能在程度上存在差异。判断时要问：

- 原文是否提供了明确评价？
- 情绪强度是否有充分依据？
- 选项是否比原文表达得更绝对、更激烈？

若没有依据，应选择更客观、程度更适中的表达。
除非文章中有包含人的主观情绪的明确表达，否则所有带有人的情感倾向的词，在没有线索时尽量不要选。

## 3.4 优先服从搭配和句法

词义相近不代表能够互换。以下差异都可能决定答案：

- 及物与不及物；
- 后接名词、介词还是从句；
- 主动与被动搭配；
- 固定介词；
- 可数与不可数；
- 词在句中的位置；
- 标点要求。

## 3.5 避免常识的过度推演

常识可以帮助理解文本，但不能代替文本证据。若一个选项必须依赖长篇想象才能成立，而另一个选项能够被句内或上下文直接证明，应选择后者。

# 4 辅助判断

以下规律可以提高定位效率，但都不是可以脱离语境直接套用的公式。

## 4.1 邻近否定词

如果空格紧邻的前后部分出现 `not` 或其他否定表达，可优先检查是否需要对立关系词。否定常常意味着对前述内容的限制或推翻，但最终必须把选项代回全文验证。

## 4.2 新段段首挖逻辑词

若新段与上段只是普通顺承，连接词有时可以省略；既然段首专门挖空，往往说明行文关系发生了较明显的变化。因此可优先检查：

1. 是否发生转折或让步；
2. 若对立不成立，是否在递进或强化前文。

## 4.3 实验条件变化

实验类文章中，如果不同对象接受不同条件或处理，作者通常会比较结果。看到条件变化时，应主动寻找结果的相同、不同或相反之处，并用文章实际表述确认。

## 4.4 举例关系

看到“复数类别或一般概念—单个具体对象”的结构时，优先检查举例关系。不要被具体对象的生词干扰，只要能判断它属于前面的类别，就可能完成逻辑判断。
