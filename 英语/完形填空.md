# 1 逻辑关系词题
## 1.1 逻辑关系
### 1.1.1 并列
**特征**：前后同方向、同层次
- `and`：和，与，以及
- `or`：或者，或
- `similarly`：类似地，同样地
- `likewise`：同样地
- `as well as`：以及，也

### 1.1.2 递进
**特征**：同方向，后项更强或更重要
- `also`：也，还
- `besides`：此外，而且
- `in addition`：此外，另外
- `moreover`：此外，而且
- `what's more`：而且，更重要的是
- `indeed`：确实，的确。表示强调，引出另一件事。
- `even`：甚至

### 1.1.3 因果
**特征**：一方是原因，另一方是结果
- `because`：因为
- `since`：因为，既然
- `therefore`：因此，所以
- `thus`：因此，于是
- `as a result`：因此，结果
- `now that`：由于，因为
- `put down to`：归因于

### 1.1.4 对立
**特征**：方向、事实、评价或预期相反。出现not，others。
- `but`：但是
- `yet`：然而，但是
- `however`：然而，不过
- `although`：虽然，尽管
- `while`：然而，尽管（表对比）
- `rather than`：而不是
- `instead of`：代替，而不是
- `instead`：句首通常翻译为相反，句中通常翻译为反而，句尾都可
- `though`：不过，可是，然而
- `even if`, `even though`：尽管`
- `even`：即使
- `whereas`：然而
- `yet`：然而，但

### 1.1.5 列举
**特征**：围绕同一观点依次展开分项
- `first`：首先
- `second`：其次，第二
- `next`：接着，下一步
- `finally`：最后

### 1.1.6 条件
**特征**：一方成立是另一方发生的条件
- `if`：如果
- `unless`：除非
- `otherwise`：否则
- `provided`：假如，只要
- `as long as`：只要
- `in case`：万一，如果

### 1.1.7 举例/总分
**特征**：一般概念后接具体实例
- `for example`：例如
- `for instance`：例如
- `such as`：比如，诸如

## 1.5 因果词不能机械成对出现

原因标志与结果标志通常不会在同一结构中重复出现。判断因果关系时，应先确定空格需要引出原因还是结果，再选择相应表达，避免只因句子涉及原因就随意选因果词。

# 2 根据空格位置判断
## 2.1 空格位于句中
优先比较空格前后的词、短语或分句。重点检查：
- 两侧语义关系；
- 固定搭配；
- 结构是否平行；
- 空格是否连接一般概念与具体实例；
- 空格前后是否出现正反方向变化。

## 2.2 空格位于句首
句首填逻辑关系词题时，首先考虑对立，其次考虑递进。
句首逻辑词可能表示两种关系：
- 本句内部两个分句之间的关系；
- 本句与前一句之间的关系。

因此必须同时阅读前一句和本句，不能只盯着空格后的内容。

## 2.3 空格处于两个逗号之间

这种位置往往具有插入语特征。可暂时把逻辑词移到句首理解，但必须判断它实际连接的是：
- 本句内部的两部分；还是
- 本句与前一句。
若去掉插入部分后，本句只是完整、自然的主谓宾结构，空格所表达的关系很可能来自句间而非句内。

# 3 选项比较与排除
## 3.2 利用反义选项确定方向

选项中出现一组反义词时，往往提示命题人在考查上下文的语义方向。此时先根据文章判断需要正向还是负向、增强还是减弱，再在对应方向中精确选择。

反义选项只是方向提示，不能替代最终的搭配和语义验证。

## 3.3 比较感情色彩和语气强弱

近义词可能分别带有正面、负面或中性色彩，也可能在程度上存在差异。判断时要问：

- 原文是否提供了明确评价？
- 情绪强度是否有充分依据？
- 选项是否比原文表达得更绝对、更激烈？

若没有依据，应选择更客观、程度更适中的表达。
除非文章中有包含人的主观情绪的明确表达，否则所有带有人的情感倾向的词，在没有线索时尽量不要选。

## 3.5 避免常识的过度推演

常识可以帮助理解文本，但不能代替文本证据。若一个选项必须依赖长篇想象才能成立，而另一个选项能够被句内或上下文直接证明，应选择后者。

# 4 辅助判断
## 4.1 邻近否定词

如果空格紧邻的前后部分出现 `not` 或其他否定表达，可优先检查是否需要对立关系词。否定常常意味着对前述内容的限制或推翻，但最终必须把选项代回全文验证。

## 4.2 新段段首挖逻辑词

若新段与上段只是普通顺承，连接词有时可以省略；既然段首专门挖空，往往说明行文关系发生了较明显的变化。因此可优先检查：

1. 是否发生转折或让步；
2. 若对立不成立，是否在递进或强化前文。
