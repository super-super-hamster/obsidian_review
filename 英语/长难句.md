
# 1 总流程

1. **找连词**：确定句子之间、成分之间的连接关系。
2. **找谓语动词**：确定每个分句的核心动作，统计分句数量。
3. **找介词结构**：先移开不构成主干的修饰成分。
4. **还原非主干**：处理从句、非谓语、后置定语、插入语和省略。
5. **按逻辑翻译**：先译主干，再译修饰；必要时重排为符合汉语习惯的顺序。

## 1.1 找连词

- 一般情况下，**N 个连接分句的连词对应 N+1 个分句/谓语动词**。

### 1.1.1 并列连词

- 常见：`and`、`or`、`but`、`yet` 等。
- 前后必须连接**相同层级、相同性质**的成分：词对词、短语对短语、句子对句子。
- 判断并列对象时，优先**从后往前找相同**。后面是句子，就先找前面的句子；后面是名词、动词或形容词，就先找同类成分。
- 多个词并列时，通常只需最后一个连词；多余的连词往往是在连接分句。

### 1.1.2 从属连词

- 常见特征：`what/when/where/which/whether/how` 等 W- 词，以及 `that`、`if`、`though`、`since` 等。
- 从属连词通常引导一个分句，也可能直接接不定式：`what to do`、`where to go`。

## 1.2 找谓语动词

### 1.2.1 常见谓语形式

- 一般时：动词原形、第三人称单数或过去式。
- 进行时：`be + V-ing`。
- 情态/将来：情态动词或 `will` + 动词原形。
- 完成时：`have/has/had + 过去分词`。
- 被动语态：`be + 过去分词`。

### 1.2.2 `-ed` 形式不要直接判定

名词后紧跟 `-ed` 形式时，它可能是：

- 过去式谓语：主语与动作是主动关系；
- 过去分词：非谓语，通常表示被动或修饰前面的名词。

判断时同时看主语与动词的主被动关系，并结合动词后面的内容验证。不要因为形式像过去式，就把它直接当成主干谓语。

## 1.3 找介词

- 常见介词：`in`、`on`、`at`、`of`、`with`、`by`、`for` 等。
- 介词引导的成分通常不构成句子主干，主要作：
  - **定语**：修饰名词；
  - **状语**：修饰谓语或整个句子；
  - **补语**：补充说明成分。
- 句子太长时，可以先把介词短语括起来或暂时移开，找出主干后再放回。
- 翻译时，英语后置的状语常提前到谓语或整句前；后置定语通常译成“……的”。

# 2 非主干结构

## 2.1 非谓语动词

非谓语不是分句的谓语，常作状语或后置定语。

- `V-ing`：通常表示主动或进行；
- `V-ed`：通常表示被动或完成；
- `to do`：常表示将来、目的或尚未确定的动作。

看到“连词 + 句子，句子”被压缩的形式，要尝试还原为完整分句。状语从句省略的常见条件是：从句与主句主语一致，且从句含 `be`；还原时补回主语和 `be`。

## 2.2 后置定语和名词扩展

名词后面可能连续跟介词短语、分词短语和定语从句。它们都是在回答“这个名词是什么样的”。

- 分词作后置定语，可还原为定语从句；
- 定语从句没有“就近修饰”原则，不能只看离它最近的名词；
- 判断先行词时，把候选名词带回从句，看语义是否成立，并检查从句缺的是主语还是宾语；

# 3 从句

## 3.1 定语从句

- `that` 本身通常不充当从句成分。`that` 后面成分完整，常见于名词性从句或同位关系；
- 定语从句中，关系词要在从句内部充当主语或宾语，因此从句通常缺一个成分；
- `in which/when/where` 等关系副词或介词加关系代词，后面可以出现完整结构，不要机械套用“后面必须缺成分”的判断。

## 3.2 `that` 的三种常见干扰

- **引导从句**：看后面是否形成分句，并根据所在位置判断功能；
- **关系词**：看从句是否缺主语或宾语；
- **指示代词**：如果 `that` 后面连谓语动词都没有，它可能只是“那个/那件事”，不引导从句。
