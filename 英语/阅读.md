# 1 通用

## 1.1 文章
- **观点倾向**：作者的观点往往与多数派相反。
- **委婉表达**：正确选项往往表述委婉、带有不确定性（如含有 `may`、`be likely to` 等）。
- 实验型文章重点多在结论处，其次是过程。重点读懂结论，而非实验过程。
- **重点关注**: `but`等转折词, `now`等表示今夕时间的词, 分号，问号。

## 1.2 选项    
- **警惕比较级**：文章中或选项中出现的比较级容易设坑，需谨慎核对后再选择。
- **相反选项**：两个意思“相反”的选项中，可能出现正确答案。

# 2 题型

## 2.1 细节题
- **定位信息收集**：必须**集齐**题干中的所有定位信息，重点关注以下语法线索：
    - **代词**：如 `they`。
    - **介词**：如 `by`。
    - **情态动词**：注意同义替换，如 `should` $\rightarrow$ `ought to`、`need to`。
- **比对与排错原则**：
    - **逐词比对**：细节题的选项一定要与原文逐词比对。
    - **防止答非所问**：“题干 + 选项”同时正确且匹配才是真正的正确答案，避免表述正确但答非所问的干扰项。
    - **主旨优先**：纠结时优先选择符合文章主旨的选项。

## 2.2 例证题
- **题干标志**：题意通常为“提到 xxx 例子，是为了说明/证明……”
    - **例子词**：`case`、`example`、`use`、`cite`、`quote`、`mention`、`refer to`
    - **说明词**：`to illustrate`、`demonstrate`、`show`、`prove`、`to...`
- **解题重点**：找例子所支撑的**观点**（观点通常出现在例子之前）
- **常见干扰项**：复述例子本身的选项。
- **特殊位置**：第一段的例证题，答案一般在**第一段最后一句**或**第二段第一句**，看完文章后再选。
    
## 2.3 推理题
- **题干标志**：`infer`、`suggest`、`imply`、`conclude`、`learn from`
- **正确选项来源**：
	- 带有 `may` 等委婉表述的词，可能为正确答案。
    - 细节与原文完全一致的同义表述，可作为正确答案。
    - 原文**转折处**常出正确答案。
        
## 2.4 词汇题与成语题
- **词汇题**：在上下文中寻找形式与逻辑上的对应关系。
- **成语/习语题**：按字面意思逐字翻译并结合语境理解，不要生搬硬套尝试寻找对应的中文成语。
    
## 2.5 作者态度题

| **态度分类** | **例如**                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------- |
| **正面态度** | `positive`、`optimistic`、`approval`、`supportive`                                                      |
| **负面态度** | `negative`、`pessimistic`、`disapproval`、`critical`、`doubtful`、`suspicious`、`skeptical`、`questionable` |
| **中立客观** | `neutral`、`objective`、`impartial`                                                                    |

**一定不选**：

| **态度分类** | **例如**                                           |
| -------- | ------------------------------------------------ |
| **漠不关心** | `uninterested`、`unconcerned`、`indifferent`       |
| **困惑迷茫** | `confused`、`puzzled`                             |
| **偏袒主观** | `biased`、`prejudice`、`contemptuous`、`subjective` |
